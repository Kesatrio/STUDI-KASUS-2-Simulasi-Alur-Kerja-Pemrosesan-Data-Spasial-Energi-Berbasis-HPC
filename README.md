# Studi Kasus 2: Simulasi Alur Kerja HPC Paralel
Studi kasus ini mengadaptasi konsep High-Performance Computing (HPC) yang berfokus pada eksekusi tugas berat atau pengolahan data berskala besar secara paralel. Skrip ini meniru cara kerja pembagian tugas ke dalam beberapa core prosesor untuk mempercepat waktu komputasi.
